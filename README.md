## Selected Work

### TicketForge, Lenovo E-Ticket Automation

Python, Selenium, Excel · [Source](https://github.com/vikas3333-singh/Lenovo-E-Ticket-Automation) · [Live demo](https://vikas3333-singh.github.io/Lenovo-E-Ticket-Automation/)

Lenovo warranty claims were eating 2.5 to 3 hours every morning. Thirty-plus tickets, all submitted by hand through the portal. I wrote a script that pulls the device list out of an Excel inventory sheet, submits the batch, and saves each confirmation number back to the sheet. Three hours became 1 minute 42 seconds, and hardware replacements now go out the same day instead of the next.

### Advanced IT Troubleshooting Utility (AITU)

Python, Batch, Bash · [Source](https://github.com/vikas3333-singh/Advanced-IT-Troubleshooting-Utility) · [Live demo](https://vikas3333-singh.github.io/Advanced-IT-Troubleshooting-Utility/)

A cross-platform diagnostic toolkit for the repairs I was doing over and over: SFC and DISM, network stack reset, cache cleanup, macOS maintenance scripts. Runs silent for Intune deployment, and has a non-destructive dry-run mode so nobody nukes a machine by accident. Routine maintenance went from about 40 minutes to 4.5, and it deflects roughly 74% of the L1 escalations that used to land on my desk.

### IT Asset Tracker

HTML5, JavaScript, Chart.js · [Source](https://github.com/vikas3333-singh/it-asset-tracker) · [Live demo](https://vikas3333-singh.github.io/it-asset-tracker/)

Built because the alternative was a spreadsheet nobody updated. Tracks device status and warranty expiry across 500+ distributed assets. The weekly audit went from 4 hours to under 20 minutes.

### Windows Autopilot Provisioning

Intune, Autopilot, Entra ID

Provisioning workflow for new-hire devices: Autopilot profiles, Intune configuration policies, and drop-ship straight to the end user. Under 20 minutes of engineer time per device, and Day 1 onboarding stops being a queue outside the IT room.
